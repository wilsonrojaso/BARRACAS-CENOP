CÓMO USAR EL SISTEMA

Guía rápida de administración de barracas
  1. Editar un ala: haz clic sobre el recuadro del ala (izquierda o derecha) de cualquier alojamiento. Se abre el formulario.
  2. Fechas del curso: en cada curso hay dos casillas con calendario: fecha de inicio y fecha de finalización. Esas fechas quedan guardadas y salen impresas en el parte.
  3. Guardar: al presionar Guardar cambios los datos quedan almacenados en el navegador y el sistema te muestra el parte de esa ala listo para copiar o enviar.
  4. Parte individual: cada ala tiene el botón 📋 Parte, y cada alojamiento el botón 📋 Parte del alojamiento (las dos alas juntas).
  5. Disponibilidad: cada ala muestra cuántos cupos le quedan libres y la barra de ocupación. Si la ocupación supera la capacidad, el sistema avisa.
  6. Alertas: el filtro ⚠️ ATENCIÓN muestra las alas con cursos ya finalizados o que terminan en 3 días o menos, para desocuparlas a tiempo.
  7. Respaldar: con ⬇ Respaldar datos descargas un archivo con toda la información. Guárdalo; si algún día se borra todo, con ⬆ Restaurar respaldo lo recuperas.
Los datos se guardan en el navegador de este computador. Para pasarlos a otro equipo, usa Respaldar datos y luego Restaurar respaldo.
